# Welcome to My Reactjs Calculator
***

## Task
Create a functional calculator using React.js that can perform basic arithmetic operations, handle square roots, and manage input validation.

## Description
This project is a simple calculator built with React.js. It supports basic arithmetic operations such as addition, subtraction, multiplication, and division. It also includes functionality for square roots and exponentiation. The calculator ensures that the input is valid and provides appropriate error messages for invalid inputs.

## Installation
To install the project, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/Chamis9/Calculator.git
   ```
2. Navigate to the project directory:
   ```sh
   cd react-calculator
   ```
3. Install the dependencies:
   ```sh
   npm install
   ```

## Usage
To run the project locally, use the following command:
```sh
npm run dev
```
This will start the development server and open the calculator in your default web browser.
